## [3] BLOCK_TIME − AOBT_3_flt 符号订正(关键基础事实)

**2025 全年 DEP(n=2,062,577 都有效)**:

| 指标 | 值 |
|---|---|
| mean | **+17.03s** |
| median | **+51.00s** |
| p10 | −310s |
| p25 | −122s |
| p50 | **+51s** |
| p75 | +183s |
| p90 | +363s |
| **正值占比(BLOCK > AOBT,BLOCK 比 AOBT 晚)** | **56.18%** |
| **负值占比(BLOCK < AOBT,BLOCK 比 AOBT 早)** | **43.17%** |
| 完全相等 | 0.65% |

**符号方向**:**BLOCK 比 AOBT 晚约 51s**(中位),即 AOBT 是航班**离开登机口**的瞬间,BLOCK 是**推出登机口 + 滑行到跑道**的瞬间(典型 ramp 时间约 1 分钟)。

**(MVT−AOBT) − (MVT−BLOCK)** 数学上恒等于 (BLOCK−AOBT):
- 实测 mean=+17.03s, median=+51.00s **完全等于** BLOCK−AOBT 的分布
- 所以 **MVT−AOBT 平均比 MVT−BLOCK 大 17s**(不是 ~16s,与名义差 1s 在舍入误差内) — 即"用 AOBT 替代 BLOCK 估算 taxi-out,平均会高估约 17s"

**差值正负原因**:正偏分布 — 56% 航班 BLOCK 晚于 AOBT(ramp 滑行正常),43% BLOCK 早于 AOBT(数据噪声、跨时段切换、航站楼较近等)。p25=−122s, p75=+183s, 差值分散度大,**不能简单说 BLOCK=AOBT**(虽然相关 1.0)。

## [2] 单变量消融(DEP 子集,只推理不重训)

> `ablation.json` — 用同一 v10 模型,逐列替换后重推理

### 消融汇总

| 操作 | EGLL Δ | LTFM Δ | global Δ |
|---|---|---|---|
| **(a) dep_queue_n_airport 按 holdout 经验分位重映射** | **-2.60s** | **-6.84s** | **+0.78s** |
| **(b) dep_mvt_cnt_5/10/15m 按 holdout 经验分位重映射** | +2.39s | +0.17s | -1.21s |
| **(c) ref_was_estimated 置 0** | **+0.00s** | **+0.00s** | **+0.00s** |
| **(d) a+b+c 全部** | -0.25s | -6.91s | **-0.76s** |

### 完整对照

| 模型/变体 | EGLL mean | LTFM mean | global mean |
|---|---|---|---|
| v1 basic30(ranking) | 1322.24 | 1235.21 | 1006.30 |
| v10 原始(ranking,DEP) | **1197.28** | **1041.46** | **963.88** |
| (a) queue 重映射 | 1194.68 (−2.60) | 1034.62 (−6.84) | 964.66 (+0.78) |
| (b) cnt 重映射 | 1199.67 (+2.39) | 1041.63 (+0.17) | 962.67 (−1.21) |
| (c) ref_est=0 | 1197.28 (+0.00) | 1041.46 (+0.00) | 963.88 (+0.00) |
| (d) a+b+c 全部 | 1197.03 (−0.25) | 1034.55 (−6.91) | 963.12 (−0.76) |

### **关键判定**

1. **(a) 队列重映射几乎不动**(EGLL -2.60s, global +0.78s):**ranking 与 holdout 队列分布同口径**,重映射到 holdout 经验分位不改变预测
2. **(b) cnt 重映射几乎不动**(EGLL +2.39s, global -1.21s):同理
3. **(c) ref_est=0 → 完全不变**: **ref_was_estimated=1 的 1.53% 行不显著影响预测**
4. **(d) 全部替换 → 几乎不动**(global -0.76s):**单变量替换队列特征无法解释 v10 的 -42s 与 EGLL 的 -125s**

### **EGLL 根因分解**

| 区间 | v10 偏移 | 单变量消融能解释 |
|---|---|---|
| v10 EGLL ranking → v1 ranking | **−125s** | **+0s**(全 4 个消融加在一起) |
| v10 LTFM ranking → v1 ranking | −194s | -7s(queue 重映射贡献) |
| v10 global ranking → v1 ranking | −42.42s | -0.76s |

**判定**:**队列特征列本身不是 v10 ranking 预测偏低的根因**。单变量替换队列/cnt/ref_est 几乎无法改变 v10 预测。**偏移必然来自 v10 模型的非线性交互** — 模型在 ranking 分布上学到的 "队列长→taxi-out 长" 关系,与在 holdout 上学到的有差异,但**这个差异不能用简单替换队列列数值来弥补**。

## 真正的根因(汇总)

| 维度 | 真相 |
|---|---|
| v10 推理时 ranking 队列列 | **与 holdout 同口径**(EGLL 1月 14.43 vs 14.75, 差 -0.32) |
| v10 ranking 上 MVT-AOBT 真实 taxi-out | **EGLL ~1379s, holdout ~1330s, 一致** |
| BLOCK−AOBT | **BLOCK 比 AOBT 晚 +51s 中位**(不是早),差值正偏(56% 正) |
| 单变量替换队列/cnt/ref_est 对预测影响 | **< 1s**, 无法解释 -42s |
| **真正的根因** | **v10 模型本身的非线性交互**, 在 ranking 数据上预测偏低 — **不是队列列数值偏小**, 不是构造缺陷, 不是时间戳错误, 不是 AOBT 覆盖 |
