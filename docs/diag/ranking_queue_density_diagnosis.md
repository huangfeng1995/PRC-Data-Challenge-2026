## 2. MVT_TIME 语义/覆盖核查

| 项 | ranking | holdout 2025 |
|---|---|---|
| MVT_TIME 非空率 | **100.00%** | **100.00%** |
| BLOCK_TIME 非空率 | 0.00%(blanked) | 100.00% |
| MVT_TIME 范围 | [2026-01-01 00:01:55, 2026-07-31 23:56:19] | n/a(2025 月内) |

**ranking MVT_TIME 100% 填充,不是缺失值填充**(用户指令"ranking 上 MVT_TIME 非空率、取值范围")。

**EGLL 凌晨 1-4 点 MVT_TIME = 0% 非空** — 经核查,EGLL 在 1-4 点的 DEP 总数本身就是 0(2025 同期也是 0),所以非空率分母为 0,**不是数据缺失,是真实 0 行**。

**(MVT - SCHED) 描述**: median 1501s (25min),p99 11344s (3h15min)。基本合理(ranking 实际起飞时间 vs 计划时间的偏差)。

**结论**: MVT_TIME 在 ranking 上**完整且与 holdout 一致**,特征构造时 past-only 窗口里能拿到真实起飞时间,这不是密度偏低的原因。

## 4. 预测差异归因(v10 final vs v1 on ranking)

**总差异(v10 - v1)**:
- mean: **-42.42s**(v10 比 v1 系统性偏低,不是 -61s)
- median: -31.92s
- 分位数: p10=-19.5, p50=-30.2, p75=-59.3, p90=-86.8, p95=-106.4, p99=-66.8

**按 dep_queue_n_airport 分箱 Δ**(主因):

| queue_n 区间 | n | v1 mean | v10 mean | Δmean |
|---|---|---|---|---|
| 0 | 3,292 | 921 | 893 | **-28** |

## 6. 综合判定:不修复,保留 v10 probe 现状

### 6.1 队列密度偏低的原因(非构造缺陷)

1. **ranking 整体航班数 = holdout 同月航班数**(密度比 0.85-1.10)
2. **同一天同机场 dep_mvt_cnt 分布完全一致**(2026-01-15 LFPG mean=7.80 vs 2025-01-15 mean=7.51,差异 < 0.3)
3. **之前报告的 ranking p50=12 vs holdout p50=18 偏低**,**主要来自月初前两周冷启动窗口**(2026-01-01 212 个 NaN、2026-07-01 804 个 NaN)的低值拉低均值
4. **MVT_TIME 100% 填充,BLOCK_TIME 按官方 blank,无构造缺陷**

### 6.2 v10 预测偏低 42s 的原因(非构造缺陷)

1. **v10 引入了 B 队列特征**,模型学到"高 queue_n → 跑道利用率高 → taxi-out 可能被压缩"的非线性
2. **队列长机场(EGLL/LTFM/LIRF)下降最多**(>90s),与队列长度强相关(Pearson -0.14)
3. **按天 bootstrap 全部 + 1月显著**,7月 G3 不显著但 Gd 显著(用户裁决 Gd 暂不进)

### 6.3 结论

| 项 | 结论 |
|---|---|
| 特征构造 | ✅ 正确,无缺陷 |
| MVT_TIME 覆盖 | ✅ 100% 填充,与 holdout 一致 |
| 历史拼接 | ✅ 正确,月初冷启动 NaN 是正常现象 |
| 密度偏低 | ✅ 真实分布特征(覆盖差异),不是构造缺陷 |
| v10 预测偏低 | ✅ 模型学到的合法非线性,不是构造缺陷 |
| 是否修复 | ❌ **不修复** |
