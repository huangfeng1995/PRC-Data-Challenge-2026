2.3 改善不是标定漂移（反事实检验）

B 的核心 bias 从 A 的 +76.02s 降到 +6.81s，看起来像是整体标定改善。 但直接对 A 做线性重标定验证：

主体段 (y≤1800) 最小二乘拟合: A_pred → true 得 a=0.70766, b=+200.934
A_L2 线性重标定后 core = 314.25 (Δ = +1.51s, 反而变差)
B_log_raw core = 300.12 (Δ = −12.61s)

线性重标定拿不到 B 的收益（甚至变差 1.51s），所以 B 的 −12.62s 不是简单的尺度/偏置修正。 它来自 log 空间中对相对误差的优化分配——代价就是长尾更保守。

C_huber 的预测区间只有 [953.4, 1015.0]，全距 61.7 秒（A 是 9036.5 秒）， 标准差 19.62（σpred/σtrue = 0.042）。模型退化成近似输出常数。
LightGBM huber 的 δ 直接取 alpha 参数。目标单位是「秒」，残差量级 ~100-200s，
而 alpha=0.9 → 几乎所有样本都落进线性区 → 梯度恒为 ±1（与残差大小无关）
→ 树只能做全局平移，无法拟合任何结构 → 预测坍缩到常数
重要限定：C 组不能作为「Huber 策略无效」的证据。 它是一个退化配置——alpha 必须与目标量级匹配（秒级目标需要数十到数百）， 0.9 是相对量纲下的默认值，直接套用必然失效。按你「不允许为降验证分硬调、参数只用常规值」的要求， 本轮不重试 alpha。若要重新评估 Huber，需要在训练折上按残差量级 principled 地选 alpha， 而不是照着 holdout 试。

smearing 因子 1.024932（ES 集残差 mean=−0.00075，mean(exp)=1.0249）， 方向符合 Jensen 不等式的预期（exp 会系统性低估）。但应用后两个月份都变差。

因子是在训练月末 11-12 月（秋末）残差上估的，对 7 月（夏季）不适用。 这与上一轮 isotonic 校准跨月失效完全同型：训练月末的 seasonal 分布不能代表 7 月。 这是第二次在同一处栽跟头——任何在 11-12 月拟合、跨到 7 月应用的后处理都会失效。

7.1 关键判断

  1. log 目标不解决方差压缩，反而加重。σpred/σtrue 0.839 → 0.744，p99 比 0.867 → 0.788，长尾幅度比全面下降。 它的 −12.62s 核心收益来自占 74% 行数的主体段，是把容量从长尾转移到主体的取舍，不是「放开尾部」。
  2. 若你的真实评测口径是 core（剔极端），B 值得重新考虑——它是 9/10 机场改善、Jan/Jul 同向、−12.6s 的一致性改善。 但按你设定的门槛（全样本对标真榜），它不通过。
  3. Huber 本轮结果无效，属配置退化而非策略失败。若要重新评估，必须按秒级目标的残差量级重新选 alpha， 且应在训练折上选、不看 holdout。
  4. 三组 best_iter 全部撞顶 2500，说明 A 本身严重欠训练。在补轮数之前， 任何目标函数改造的结论都只在「2500 轮这个欠训练点」上成立，不能外推。

7.2 建议的下一步（按优先级）

  • 先补轮数：三组都撞 cap，学习曲线显示 8000 轮仍在单调下降。欠训练状态下比较目标函数意义有限。
  • 先确认榜单极端值口径：60 行占 full 口径 SSE 的 70%–73%。口径决定 B 是「−12.6s 可采纳」还是「+4.5s 不可采纳」。
  • 若还想试尾部改造，方向应是放开而非收紧：显式的尾部加权/分段目标， 或对长尾段单独建模，而不是 log 这种全局压缩变换。
  • 不要在 11-12 月拟合跨月后处理：这是本项目第二次因此失效（上次是 isotonic）。 若必须做，应改用能代表 7 月的折（如按月 OOF 的 7 月前一个月，或多折平均）。
